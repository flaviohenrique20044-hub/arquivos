# Arquivos privados — Documentação Flavin

Este repositório privado armazena os documentos TXT criados pela interface pública: https://flaviohenrique20044-hub.github.io/documentacao-flavin/

Para acessar e editar, crie um GitHub fine-grained personal access token restrito a este repositório com permissão Contents: Read and write. Cole-o apenas no campo de acesso do site, via HTTPS. Nunca publique tokens nem senhas no repositório público.

O token permanece somente na memória da aba. O site não implementa OAuth; os documentos são protegidos pela privacidade deste repositório e pela autorização do token.
